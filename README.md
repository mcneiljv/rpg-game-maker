## About

This is **RPG Game Maker**, a game built using **GameMaker Studio**. It includes basic RPG elements like rooms, sprites, objects, scripts, and tilesets. The goal is to learn, experiment, and build a fun RPG foundation.

---

## Features

Here are some of what this project currently has / aims to have:

- Basic player movement
- Room(s) layout (e.g. `rooms/Room1`)  
- Tilesets for environment design (`tilesets/ts_house_tiles`)  
- Sprite assets (`sprites/`)  
- Objects (`objects/`)  
- Game logic via scripts (`scripts/`)  
- Macros / helper scripts (`scripts/scr_macros`)  

Future ideas might include:

- Combat system  
- Inventory system  
- NPC interactions / dialogues  
- Saving & loading game state  
- More rooms, maps, and visual polish

## Project Structure

Here’s how the repo is laid out currently:

/objects/               — GameMaker objects (player, enemies, etc.)  
/options/               — Configuration files / settings  
/rooms/                 — Rooms (levels / scenes), e.g. Room1  
/scripts/               — Logic scripts, macros, utilities  
/sprites/               — Sprite image assets  
/tilesets/              — Tileset graphics (for building rooms)  
rpg-game-maker.yyp      — GameMaker project file  
.gitignore              — Files and folders to ignore in Git  
.gitattributes          — Git attributes (if needed)

## Requirements

To work with or build this project, you’ll need:

- **GameMaker Studio** (version compatible with `.yyp` format)  
- Appropriate export modules if you want to build for specific platforms (Windows, Mac, etc.)  
- (Optional) A code editor / text diff tool that handles GameMaker’s JSON-like files well  
- Git, if you want to version-control or collaborate locally

## Getting Started

If you want to run or contribute to this project locally:

1. Clone the repo:  
   `git clone https://github.com/mcneiljv/rpg-game-maker.git`
2. Open `rpg-game-maker.yyp` in GameMaker Studio.  
3. Import any missing assets (if needed).  
4. Run the game from GameMaker (choose your target platform).  
5. Make changes, test, commit, push.

## How to Contribute

Contributions are welcome! If you want to help:

- Pick or suggest a feature / bug to work on  
- Create a new branch for your work (e.g. `feature/npc-dialogue`)  
- Fork & submit a Pull Request when your work is ready  
- Write clear commit messages  
- Try to avoid merge conflicts by communicating who is editing which room / object / script
